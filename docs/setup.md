# Setup Guide

## Prerequisites

- A modern web browser.
- Git for cloning and contributing.
- Node.js 18+ for repository checks.

## Run the Application

```bash
git clone https://github.com/JainishK7/Openshelf.git
cd Openshelf
```

Open `index.html` directly or serve the directory:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Run Checks

```bash
npm test
npm run validate
```
